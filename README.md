# Programming Styles: Exercise 1

## Intro

I'm using TypeScript to implement the term frequency program.

## Environment

Require: Node.js v24 or later

1. After installing Node.js, run below command to make sure the environment is good to go.

```bash
node -v
```

2. Confirm it prints v24 or later, please change path to the exercise.

```bash
cd ./20261005-ex1
```

3. Install the dependencies:

```bash
npm i
```

4. Run the program:

```bash
node ex1.ts ../pride-and-prejudice.txt
```
